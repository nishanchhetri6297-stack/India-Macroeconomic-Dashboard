# India Macroeconomic Dashboard

## Overview

This project presents an Excel-based dashboard analyzing key macroeconomic indicators of India from 2019 to 2025.

The dashboard provides a simple visual overview of India's economic performance and monetary conditions using trend charts, KPI cards, and economic insights.

## Key Indicators

The dashboard covers four major indicators:

- GDP Growth (%)
- CPI Inflation (%)
- Repo Rate (%)
- Bank Credit Growth (%)

## Key Insights

### Economic Recovery
India experienced a sharp economic contraction in 2020, followed by a strong recovery in 2021.

### Inflation Trend
Inflation remained relatively elevated during 2020–2022 before moderating in the following years.

### Monetary Conditions
The repo rate increased substantially during the monetary tightening period before easing in 2025.
